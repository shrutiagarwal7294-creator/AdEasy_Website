# AdsEasy Media — Website Package

Open `index.html` in any browser. No build step, no server required (the site also works when hosted on any static host — Netlify, Vercel, S3, cPanel).

## What's inside
- 47 pages: Home, About, 18 service pages, 11 industry pages, Services/Industries hubs, Free Tools (8 working calculators with charts, download & share), Blog + 6 full articles, Case Studies, Master FAQ, Contact (6 forms), Privacy/Terms/Cookies

- UX: sticky nav + mega menus, scroll/hover animations, counters, accordions, testimonial slider, floating WhatsApp, back-to-top, sticky mobile CTA, mobile-first responsive

4. **Certifications** on About — keep only the ones you actually hold.
